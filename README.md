# PayPing

Автономное Android-приложение для напоминаний о предстоящих списаниях (подписки, кредиты, аренда, налоги), чтобы вовремя пополнять счёт. Работает полностью локально на устройстве без сервера.

## Что реализовано (Этап 1 — MVP)
- **Хронологический список списаний:** группировка *Просрочено → Сегодня → Ближайшие → Позже*.
- **Сводка потребностей:** сумма на ближайшие 7 дней и до конца месяца с разбивкой по валютам.
- **Гибкое расписание и уведомления:**
  - индивидуальное время уведомления (`ЧЧ:ММ`) для каждого списания;
  - повторяемость (*разово / еженедельно / ежемесячно / ежегодно*) с корректным переносом концов месяцев (например, 31 → 28/29 → 31);
  - множественный выбор дней предварительного напоминания (в день списания, за 1, 2, 3, 5, 7, 14 дней);
  - точные будильники через `AlarmManager` + восстановление после перезагрузки (`BOOT_COMPLETED`);
  - кнопка **«Готово»** как в карточке, так и прямо в уведомлении.
- **История платежей:** снимок каждого подтверждённого платежа с датой оплаты.
- **Настройки и бэкап:** язык (`RU / EN`), тема (`Системная / Светлая / Тёмная`), валюта по умолчанию, экспорт и импорт в `.json` (замена или объединение).

## Сборка APK через GitHub Actions
При каждом `push` в ветку `main` (или вручную через вкладку **Actions → Build PayPing Android APK → Run workflow**) автоматически:
1. Запускаются unit-тесты (`gradle testDebugUnitTest`).
2. Собирается `app-debug.apk` (`gradle assembleDebug`).
3. Готовый APK загружается в артефакты запуска под именем **`payping-debug-apk`**.

## Стек
